# Arbeitsauftrag: Einflussfaktoren auf das Wachstum von Bakterien

## Ziel der Aufgabe
Du untersuchst, **welche Umweltfaktoren das Wachstum von Bakterien beeinflussen**  
und wie sich Veränderungen dieser Faktoren auf die Wachstumskurve auswirken.

---

## So arbeitest du auf der Seite

1. **Name und Klasse eintragen**  
   → Das brauchst du später für die Sicherung.

2. **Übersichtsseite nutzen**  
   Du siehst fünf Einflussfaktoren:
   - Temperatur  
   - Nährstoffe  
   - pH-Wert  
   - Sauerstoff (O₂)  
   - Wasserverfügbarkeit (Salz/Zucker)

3. **Einflussfaktoren bearbeiten**
   - Öffne **jeden Faktor einzeln**
   - Lies den Informationstext sorgfältig
   - Bearbeite **alle Aufgaben**
   - Nutze die **Simulation**:
     - Bewege den Schieberegler
     - Beobachte, wie sich die Wachstumskurve verändert
   - Klicke am Ende auf  
     **„Als abgeschlossen markieren“**

   👉 Erst wenn **alle Aufgaben richtig** sind, gilt der Faktor als erledigt.

4. **Fortschritt kontrollieren**
   - Oben siehst du, wie viele Faktoren du bereits abgeschlossen hast
   - Ziel: **5 / 5**
